# Arbitrary file write from downloading malicious torrents

File paths from torrent metadata were not sanitized properly in `vortex-bittorrent`. A malicious torrent could exploit path traversal or symlink following to cause the library to create or write to files outside the intended download directory.

This could allow an attacker to overwrite existing files that the application has permission to read and write, provided the torrent's corresponding data is downloaded.

This was fixed in version 0.8.0 which adds validation to file paths and directory relative filesystem operations.
