# `set_argv_index` and `set_omit` dereference `usage` unchecked

`set_argv_index` and `set_omit` are safe. Both write through `(*self.usage)` with no null check. `usage` is a raw pointer. A null or dangling `usage` makes the write undefined behavior.

0.0.6-alpha.6, the current crates.io release, still has both functions. The report has had no maintainer reply since 2024-12-09.
