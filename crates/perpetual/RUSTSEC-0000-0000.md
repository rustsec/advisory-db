# Histogram builders index with `get_unchecked` from safe functions

`from_parent_child` and `from_parent_two_children` on the histogram type are safe and index `hist_tree` with `get_unchecked`. A caller can pass an index past the slice. The report against 0.7.8 showed that.

The pointer-taking copies in `bin.rs` were later marked `unsafe` (present as `pub unsafe fn` in 0.10.0). The histogram functions named in the report were not. 3.0.0-rc.2, the current crates.io release, still has `pub fn from_parent_child` calling `hist_tree.get_unchecked(root_num)`. No release removes that safe API.
