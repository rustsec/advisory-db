# Memory corruption bug on `VipsImage` type

The `VipsImage` type contains a raw pointer which can be duplicated without incrementing the associated reference counter via a derived `Clone` implementation.

If an instance of `VipsImage` is duplicated through `Clone` and both instances are dropped memory corruption can occur.
