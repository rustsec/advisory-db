# `lwd-uri-util` was removed from crates.io for malicious code

The `lwd-uri-util` crate exfiltrated SSH keys, AWS credentials, and other
environmental metadata and secrets when any crate using it was built.

The malicious crate had 8 versions published on 2026-11-09 approximately 12
hours before removal and had no evidence of actual usage. This crate had no
dependencies on crates.io.

Thanks to [Bitbison](https://bitbison.io/) for the report.
