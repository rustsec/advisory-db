# `get_str` and `get_string` build a `str` without checking UTF-8

`get_str` and `get_string` are safe. In 0.10.1 they still call `str::from_utf8_unchecked` on a caller-supplied `&[u8]` or `Vec<u8>`. A safety comment tells the caller to pass UTF-8, but the functions are not `unsafe`, so safe Rust can pass invalid bytes.

`from_utf8_unchecked` requires the bytes to be valid UTF-8. Violating that is undefined behavior.

The report has been open since 2024-11-30. No maintainer reply, and 0.10.1 is still unpatched.
