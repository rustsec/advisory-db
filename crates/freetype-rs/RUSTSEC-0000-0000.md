# `Face::clone` and `Face::reference` can overflow FreeType's reference counts

`Face::clone` takes new references on the face and on its library through `FT_Reference_Face` and `FT_Reference_Library`, and `Face::reference` takes a new reference on the face through `FT_Reference_Face`. FreeType keeps both counts in plain `int` fields and increments them with no upper bound.

`std::mem::forget` is safe, so safe code can call either method repeatedly and forget any returned `Face` until a count reaches `INT_MAX`. The next call then performs a signed integer overflow inside FreeType, which is undefined behavior.

A driver with no `unsafe` code triggers this with freetype-rs 0.38.0 and FreeType 2.15.0. UndefinedBehaviorSanitizer reports the overflow at the increment.

No fixed version is available.
