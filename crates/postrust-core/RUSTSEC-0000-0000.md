# Deeply nested `select` or logic filter aborts the process

The `select` query parameter and the `or=` / `and=` logic filters are parsed
recursively, one level per parenthesis, with no depth limit. A single request
nested a few thousand levels deep (about 15 KB of query string) overflows the
thread's stack, which aborts the whole process and fails every in-flight
request.

No token is needed: the request is parsed before it is authorized. No data is
read or changed.

Version 2.4.1 counts parenthesis depth before parsing and refuses a value
nested more than 64 levels deep with 400 `PGRST100`. Upgrade `postrust-core`
(and with it `postrust-server` or `postrust-lambda`) to 2.4.1 or later; 3.0.0 is
also fixed. The Cloudflare Worker build, `postrust-worker`, is fixed in 1.0.1.
