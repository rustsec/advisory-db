# Relative Path Traversal (CWE-23) in `decompress_impl` that enables an arbitrary file write.

All versions of `sevenz-rust` fail to verify file paths when extracting in `decompress_impl` (the underlying function used in the exposed decompress api functions). This allows a maliciously crafted archive to extract outside the extraction directory, from both relative paths such as `../../../...` or absolute paths like `C:\\...` or `/etc/...`, which could lead to file disclosure or remote command execution in combination with other flaws or social engineering.

The project has been abandoned and the repository has been deleted, so no upstream fix is expected. Users should migrate away from the library in favor of a modern up-to-date 7z library such as `sevenz-rust2`.
