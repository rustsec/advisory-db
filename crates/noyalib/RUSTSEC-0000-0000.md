# JSON Schema validation: pattern backtracking, error growth and external $ref

### Impact

Schema `pattern` and `patternProperties` compiled with a backtracking engine, so a hostile pattern cost minutes per validation. Violations were collected without a cap: an 18 KB schema against a 1 MiB instance built a 1 GB error string. No `$ref` retriever was installed, so a build that enabled `jsonschema`'s `resolve-file` or `resolve-http` feature let a schema read local files or fetch URLs. This matters wherever the schema is attacker-controlled, as in `noyalib-mcp`'s `noyalib_validate`.

### Patches

Fixed in 0.0.55. Patterns use a linear-time engine unless `backtracking_patterns(limit)` opts in, collected errors are capped in count and size, oversized schemas are refused, and every external `$ref` is refused.

### Workarounds

Validate only against schemas you trust.
