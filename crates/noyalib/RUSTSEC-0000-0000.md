# Parsing a long line takes quadratic time

### Impact

Each plain scalar searched to the end of its line for a comment or line break. A single line of many short flow entries therefore cost the line length once per entry: 400 KB took seconds, 1.6 MB close to a minute. The cost was paid before any budget could refuse the input, so the strict profile did not help.

### Patches

Fixed in 0.0.55. The search result is reused for the rest of the line, and parsing is linear in the line length. Parse results are unchanged.

### Workarounds

Cap the input size well below 100 KB, or reject input with very long lines, before parsing.
