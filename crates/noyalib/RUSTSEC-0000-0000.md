# Borrowed API skips the alias size budget and other limits

### Impact

`borrowed::from_str_borrowed*` enforced `max_alias_expansions` but not the alias expansion size estimate the owned loader uses. It also skipped `max_events`, `max_nodes`, `max_total_scalar_bytes`, `max_mapping_keys`, `max_sequence_length`, `max_documents`, `alias_anchor_ratio` and the duplicate-key policy. A 432-byte billion-laughs document was accepted after 56 seconds at 923 MB of memory.

### Patches

Fixed in 0.0.55. The borrowed loader charges the same shared budget meter as every other loader, and the billion-laughs document is refused at once.

### Workarounds

Use the owned `from_str` family for untrusted input.
