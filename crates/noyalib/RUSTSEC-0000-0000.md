# Alias chains build values deeper than max_depth

### Impact

Each anchor in a chain can nest the previous one inside a few brackets. Every level passes the `max_depth` check, but the expanded value is the sum of all levels. A 22 KB document built a value about 10,000 levels deep. Dropping it, or any recursive walk, overflowed the stack and aborted the process, which Rust cannot catch. Every loader that expands aliases was affected, including `from_str`, typed deserialization and `parallel`.

### Patches

Fixed in 0.0.55. An alias is charged its anchored subtree's height on top of the depth where it stands, and every entry point refuses the chain with `RecursionLimitExceeded`.

### Workarounds

Refuse anchors with `ParserConfig::strict()`, or lower `max_alias_expansions`, for untrusted input.
