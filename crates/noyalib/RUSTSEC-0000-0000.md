# CST edit fragments are parsed with no depth limit

### Impact

`cst::Document::set`, `replace_span` and the other fragment editors built a green tree from the new fragment before the configured re-parse ran, with no depth limit. A fragment of 100,000 nested `[` overflowed the stack and aborted the process. `noyalib-mcp` (`noyalib_edit`, `noyalib_set`) and `noyalib-wasm` expose these editors to callers.

### Patches

Fixed in 0.0.55. Fragment editors return `Error::RecursionLimitExceeded` above the document's `max_depth`, and dropping a green tree no longer recurses per level.

### Workarounds

Reject edit fragments whose bracket or indentation nesting exceeds a small bound before calling the editors.
