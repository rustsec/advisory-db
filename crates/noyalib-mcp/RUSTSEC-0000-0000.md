# File tools: mode reset, symlinked temp files and a confinement race

### Impact

Writes went through a temp file with a predictable name, opened without `O_EXCL` and with default permissions. A rewrite turned a 0600 file into 0644, and someone able to create files in the directory could plant a symlink at the temp name so the write landed outside the root. The root check canonicalised a path and then reopened it by name, so swapping a directory for a symlink in between escaped the root on reads and writes.

### Patches

Fixed in 0.0.55. Temp files are created exclusively with a random name and the target's mode, and paths are resolved and opened component by component from a root handle without following symlinks.

### Workarounds

Do not point `--root` at a directory other users or untrusted processes can write to.
