# File tools block on FIFOs and read whole files

### Impact

The file tools read with `read_to_string` on the async runtime's worker threads. One call per core on a FIFO wedged the whole server, `ping` included, and a 4 GiB file was read in full before any size limit applied.

### Patches

Fixed in 0.0.55. Only regular files are read, reads stop one byte past the document limit, and file I/O runs off the async workers.

### Workarounds

Keep FIFOs and very large files out of the `--root` directory.
