# SSE transport accepts any Host and Origin (DNS rebinding)

### Impact

With `--transport sse`, the server checked neither the `Host` nor the `Origin` header. A web page on an attacker's domain could rebind its name to 127.0.0.1 and then drive the file tools through the user's browser: it read a canary file with `noyalib_get` and rewrote it with `noyalib_set`. The streamable HTTP transport was not affected.

### Patches

Fixed in 0.0.55. Both SSE routes refuse a non-local `Host` or `Origin` with 403, and POST requires `Content-Type: application/json`.

### Workarounds

Use the default stdio transport, or the streamable HTTP transport.
