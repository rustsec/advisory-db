# `from_winapi_d3d12_resource_desc` dereferenced a caller-supplied device pointer

In 0.18.0 through 0.27.0, `from_winapi_d3d12_resource_desc` was a safe function. It turned `device: *const winapi ID3D12Device` into a reference and transmuted the resource description. A null or dangling device pointer is undefined behavior, and safe Rust could pass one.

The maintainer agreed the function needed to be `unsafe` and removed the winapi helper. 0.28.0, published 2025-09-26, no longer contains it. 0.27.0 was the release current when the report was opened on 2024-12-10.
