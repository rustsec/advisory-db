# `qpak-lib`: PAK archive extraction is vulnerable to path traversal (zip-slip / tar-slip)

### Summary

`PakFile::extract` and `PakFile::extract_sync` write each PAK entry to
`dest_dir.join(entry_path)` using the path stored in the archive's table, with no
check for `..` components or absolute paths. A malicious `PACK` archive whose table
entry name contains `../`, or an absolute path can cause files to be written outside the
destination directory chosen by the caller. This is a "zip-slip" / "tar-slip"
directory-traversal arbitrary file write (CWE-22).

### Related

This advisory covers the `qpak-lib` library crate, which contains the vulnerable
code. The `qpak` command-line crate, which reaches this flaw through its `unpack`
command, is tracked in its own advisory.
