# Random-array constructors write into an uninitialized `Vec`

`gen_random_array` allocates `Vec::with_capacity(size)` and then, for every index, writes with `get_unchecked_mut` before `set_len`. Those slots are not initialized, so the write is undefined behavior. Public helpers such as `random_normal` call this function.

2.0.0-rc3, the current crates.io release, still contains the same loop. The report has had no maintainer reply since 2025-03-04.
