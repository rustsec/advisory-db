# Unauthenticated remote stack-overflow DoS: recursive built-in decoders bypass the decoding DepthGauge

The binary decoder in the `opcua` crate bounds recursion with a `DepthGauge` / `DepthLock`, but it is obtained on only two paths: `ExtensionObject::decode` (`lib/src/types/extension_object.rs:95`) and the nested-`Variant` branch (`lib/src/types/variant.rs:834`). Several other recursive built-in decoders do not obtain it, so attacker-nested input recurses without bound, overflows the stack, and aborts the process. Unauthenticated remote DoS, CWE-674, CVSS 3.1 7.5. This is an incomplete fix of CVE-2022-25903, which was reported against this crate and added the DepthGauge for `ExtensionObject` and nested `Variant` only.

Unguarded recursion cycles (verified at commit fcc89d8; default OPC-UA binary encoding):

- `DiagnosticInfo::decode` self-recursion on the inner-diagnostic branch - `lib/src/types/diagnostic_info.rs:175-177`.
- `Variant::decode` DATA_VALUE branch (`lib/src/types/variant.rs:836`) into `DataValue::decode` (`lib/src/types/data_value.rs:123`), which recurses back into `Variant::decode`.
- `Variant::decode` DIAGNOSTIC_INFO branch - `lib/src/types/variant.rs:838`.

Reachability: unauthenticated, default binary encoding. Client-side on every response (`ResponseHeader.service_diagnostics` is a `DiagnosticInfo`, decoded on every response); server-side on a `SecurityPolicy::None` endpoint.

Remediation: obtain a `DepthLock` on every recursive built-in decode (`DiagnosticInfo`, `DataValue`, and the DATA_VALUE/DIAGNOSTIC_INFO branches of `Variant::decode`), or centralise the guard.

The `opcua` crate is superseded by `async-opcua` (freeopcua), which shares the same defect (see FreeOpcUa/async-opcua#312 and the async-opcua-types advisory). The `opcua` crate appears unmaintained (last commit Oct 2024), so no fix is available (patched = []).

Reported by Copperfault LLC (source review + benign unit-test validation on the shared code).
