# Verifier accepts proofs for arbitrary commitments

In affected versions, the Ligerito verifier accepted proofs that do not open
the committed polynomial. A prover could commit to arbitrary data and produce a
proof that verifies, so a valid proof gave no assurance about the committed
polynomial or any claimed evaluation.

The final Ligero consistency check was a no-op, the sumcheck did not involve
the committed witness, the Reed–Solomon generator rows and fold order were
wrong, and the GF(2^32) to GF(2^128) conversion was a bit copy rather than a
field embedding.

Version 0.7.0 replaces the protocol core. Proofs produced by earlier versions
are incompatible. Upgrade to 0.8.0 or later, since 0.7.x is affected by a
separate weak-challenge issue. All versions before 0.8.0 have been yanked.

Reported by Chris (LimeChain).

For details, see <https://github.com/rotkonetworks/ligerito/security/advisories/GHSA-7pp8-58px-7452>.
