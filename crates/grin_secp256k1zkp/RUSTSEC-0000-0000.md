# Memory corruption bug on `AggSigContext` type

The `AggSigContext` type contains a raw pointer which can be duplicated via a derived `Clone` implementation. 

If an instance of `AggSigContext` is duplicated through `Clone` and both instances are dropped memory corruption can occur.
