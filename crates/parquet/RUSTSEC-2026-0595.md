# Apache Arrow Rust: Bloom filters written as plaintext when writing encrypted Parquet

When writing an encrypted parquet file with a column with bloom filters, the header
and bitsets of the bloom filter are written in plaintext in the final parquet.

Patched versions now reject writing bloom filters when encryption is enabled, raising
an error at runtime.

Existing encrypted parquet files written with bloom filters are still vulnerable,
and it is recommended to rewrite those files with bloom filters disabled if possible.

Credit to Yanzhi Xin (autoCAT6) for finding this.
