# Validating Matrix key IDs may panic

Using `key_id::validate` may panic if the `algorithm` part of the key ID is
longer than 255 bytes and contains non-ASCII characters. The affected versions
assumed that the length of the first part containing the encryption or signing
algorithm (the part before the colon) would fit into a `NonZeroU8`, but the
length of the first part wasn't validated.
