# Validating Matrix Content URIs may panic

Using `mxc_uri::validate` may panic if the server name part of the URI is larger
than 249 bytes. The affected versions assumed that the length of the first part
of the URI (`mxc://{server_name}`) would fit into a `NonZeroU8`, but the length
of the server name wasn't validated and the Matrix specification actually allows
the server name to have a maximum length of 261 bytes.
