# isl-cli MCP `tls_probe` reaches internal networks

The MCP server in `isl-cli` 0.1.0 (`isl mcp`) let an agent probe loopback,
private and link-local addresses, including cloud metadata endpoints, with
its `tls_probe` tool. An agent steered by a prompt injection could use this
to map the internal network. Probes also had no absolute deadline, DNS-over-HTTPS responses were not
size-limited, `isl serve` bound every interface by default, and
peer-supplied text reached the terminal unsanitized.

`isl-cli` 0.2.0 refuses internal targets unless `ISL_MCP_ALLOW_PRIVATE=1`,
gives every probe a 30-second deadline, caps DNS-over-HTTPS responses at
64 KiB, binds `isl serve` to 127.0.0.1 by default, and replaces control
characters in peer text.
