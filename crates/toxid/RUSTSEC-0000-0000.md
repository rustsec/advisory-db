# `toxid` was removed from crates.io for malicious code

`toxid` attempted to provide a veneer of utility while simultaneously using
`bsr58` to indirectly spawn a `hesk` task to exfiltrate browser state and
Exodus wallets.

The malicious crate had 1 malicious version published on 2026-11-18,
approximately 6 hours before removal, and had no evidence of actual usage.
approximately _time period_ before removal and had no evidence of actual usage.
This crate had no dependencies on crates.io.

Thanks to the Rust Foundation's crate scanning project for detecting this
campaign.
