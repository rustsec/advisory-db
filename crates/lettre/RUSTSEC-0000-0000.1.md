# Missing dot-stuffing after a bare LF or CR allows SMTP command injection

Someone who controls the content of a message with bare LF or CR line endings
can end it early with `\n.\n` on a server that takes a bare LF for a line
ending. What follows is read by the server as SMTP commands, which can be used
to send other messages over the same authenticated connection.

This affects messages passed to `send_raw`, and message bodies that are sent
without being encoded. The LF line endings of a `String` body are converted to
CRLF before it is sent.
