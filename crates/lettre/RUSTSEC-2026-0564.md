# Panic on a mailbox display name containing CR or LF allows denial of service

A `Mailbox` whose display name contains a CR or LF panics when it is formatted
or put in a header such as `From` or `To`. Someone who can choose a display
name, for example the name of a user a message is sent to, can crash the
thread or task building the message.

Applications that take display names only from trusted input are not exposed.
