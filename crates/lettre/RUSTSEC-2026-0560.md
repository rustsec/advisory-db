# STARTTLS response injection allows a man-in-the-middle to forge SMTP replies

A man-in-the-middle can append replies of their own to the cleartext reply to
`STARTTLS`. The client takes them for the server's replies to the commands it
then sends over TLS, so the attacker can, for example, make a message that the
server rejected look accepted.

Only connections upgraded with `STARTTLS` are affected (`Tls::Required` and
`Tls::Opportunistic`, as set up by `starttls_relay`). Implicit TLS
(`Tls::Wrapper`, as set up by `relay`) is not.
