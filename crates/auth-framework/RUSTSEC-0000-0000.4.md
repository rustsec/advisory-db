# Four low-severity defects (symlink write in feed extraction, 1024-byte comparison truncation, username control characters, fabricated audit-log entries)

Four defects were found and fixed together. Severity is low for each: the first needs a malicious or hijacked threat-feed archive; the second only matters for inputs longer than 1024 bytes.

1. **tar.gz feed extraction followed symlink entries.** `extract_tar_gz` (threat-intelligence feed management) checked paths lexically and then unpacked entries, so an archive with a symlink entry followed by a file under it could write a file outside the destination directory. Reachable when a configured threat-intelligence feed filename ends in `.tar.gz`; the attacker is whoever controls or compromises that feed, or a network attacker without TLS. Introduced in 0.5.0-rc18; affects 0.5.0-rc18 up to 0.5.0-rc44 and every 0.6.0 pre-release before rc69. Not present in 0.4.x. Fixed in 0.5.0-rc45 and 0.6.0-rc69.
2. **`validate_username` accepted control characters** when the `unicode-support` feature was enabled (0.4.x up to 0.4.13). Fixed in 0.4.14, first published in 0.4.22; already fixed in every published 0.5 and 0.6 release.
3. **`get_permission_audit_logs` returned fabricated entries** (placeholder user ids) instead of real audit records (0.4.x up to 0.4.15). Fixed in 0.4.16, first published in 0.4.22; already fixed in every published 0.5 and 0.6 release.
4. **Constant-time comparison helpers compared only the first 1024 bytes.** `secure_string_compare` (and `constant_time_eq`, `verify_token`, which delegate to it) truncated at 1024 bytes on 0.4.0 to 0.4.17; from 0.5.0-rc18 the shared primitive `constant_time_eq_bytes` truncated too, so every caller of `constant_time_compare` (MFA/TOTP and backup codes, OAuth client secrets and PKCE, session user-agent check) was affected on the 0.5 and 0.6 lines. Only inputs longer than 1024 bytes that differ after byte 1024 compared equal; TOTP codes, backup codes and PKCE values are far shorter.

Upgrade to 0.4.22 or later on 0.4.x, 0.5.0-rc45 on 0.5, or 0.6.0-rc69 on 0.6.
