# `Debug` output prints a TOTP secret and OAuth 1.0a token secrets

- `api::mfa::MfaSetupResponse.secret` (TOTP shared secret): `#[derive(Debug)]` from **0.4.1** (0.4.0 has no `api/mfa.rs`) through 0.4.34 (0.4.40
  redacts), 0.5.0-rc1 through rc53 (rc60 redacts), 0.6.0-rc41 to rc98 derived; rc101 to rc114 hand-written `Debug` that still printed `secret`.
- `protocols::oauth1::RequestTokenResponse` / `AccessTokenResponse.oauth_token_secret`: `#[derive(Debug)]` from **0.5.0-rc18** (first release with
  `protocols/oauth1.rs`) through rc53 (rc60 redacts); 0.6.0-rc41 to rc101 derived, rc109 to rc114 hand-written and still printing it.
- Fixed in 0.4.40 / 0.5.0-rc60 (mfa; oauth1 too in rc60) / 0.6.0-rc121 (all three, plus `BackChannelLogoutManager.rsa_signing_key`).
  Evidence: struct attributes and Debug impls compared in every published version's source; Verified by reading source, not by executing them. The 0.4.40 oauth1 types do
  not exist (no `oauth1.rs`).

Impact is unchanged: only where an application Debug-formats the value (log, panic, error report); not exposed to a remote caller by the library.
