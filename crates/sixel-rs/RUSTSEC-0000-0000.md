# `Encoder::clone` can wrap libsixel's reference count and free a live encoder

`Encoder::clone` calls `sixel_encoder_ref`, which increments an `unsigned int` with no upper bound in the libsixel 1.8.6 copy that sixel-sys builds. `std::mem::forget` is safe, so safe code can clone an `Encoder` and forget the clones until the count wraps and is too small for the handles still alive. Dropping one handle then frees the encoder while another is still live.

A `#![forbid(unsafe_code)]` driver triggers this with sixel-rs 0.5.0. AddressSanitizer reports a heap use-after-free on the next call through the surviving handle.

No fixed version is available.
