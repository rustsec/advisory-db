# `webhook_commands` was removed from crates.io for malicious code

`webhook_commands` attempted to send telemetry from the execution environment
to an arbitrary URL.

The malicious crate had 1 version published on 2026-02-13, approximately 9
months before removal, and had no evidence of actual usage. This crate had no
dependencies on crates.io.

Thanks to [Bitbison](https://bitbison.io/) for the report.
