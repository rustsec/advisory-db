# Sending custom to-device messages may panics

Sending a custom to-device message (by calling `Device::encrypt_event_raw` or
`OlmMachine::encrypt_content_for_devices` in matrix-sdk-crypto, can panic when
using `IdentityBasedStrategy` if the recipient does not have cross-signing keys.

This does not affect sending Megolm sessions to devices.
