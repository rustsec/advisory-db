# Memory corruption bug on `obj_parameters` type

The `obj_cparameters` type contains a raw pointer which can be duplicated via a derived `Clone` implementation. 

If an instance of `obj_cparameters` is duplicated through `Clone` and both instances are dropped memory corruption can occur.
