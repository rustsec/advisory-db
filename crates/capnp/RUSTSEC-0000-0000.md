# `set_capability_pointer` dereferenced a raw pointer in a safe function

`set_capability_pointer` lived in `capnp::private` and was `pub fn`. It wrote through `reff: *mut WirePointer` with no null check. The module is public because generated code calls it, so downstream crates could call the safe function too.

The maintainer agreed and marked it `unsafe` in pull request 563. That change is in 0.21.1, published 2025-05-26, the day the issue was closed. 0.21.0 and the 0.20.6 line are still the safe `pub fn`. Those older release lines were not backported.
