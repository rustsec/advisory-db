# Apache Arrow Rust: Improper validation of RunEndEncoded arrays allows out of bounds reads

Improper validation of RunEndEncoded arrays via `ArrayData::validate_values` can
allow reading data beyond the bounds of the child values array when reading the
last value via APIs such as `TypedRunArray::value`.

Patched versions now properly validate the contents of RunEndEncoded arrays to prevent
allowing reading out of bounds of the specified array data.

Credit to Adam Korczynski of Ada Logics for reporting this and Anthropic for finding
this.
