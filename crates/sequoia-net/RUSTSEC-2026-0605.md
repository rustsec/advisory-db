# Unbounded download buffering enables denial of service via malicious HKP or WKD server

A malicious HKP or WKD server could return a very large response that when
buffered by `sequoia-net` triggers an out-of-memory error.  By default, the
client now aborts the download after fetching more than 8 MB of data.  This
limit can be customized.
