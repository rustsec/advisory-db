# Panicking `Drop` implementation could lead to UB

Multiple functions dropped generic parameters but didn't properly handle the unwinding case, leading to broken invariants.

Reported by [tooson9010-spec](https://github.com/tooson9010-spec) and [Evian-Zhang](https://github.com/Evian-Zhang).
