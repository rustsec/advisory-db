# `qpak`: `unpack` command is vulnerable to path traversal (zip-slip / tar-slip)

### Summary

The `qpak` command-line tool extracts PAK archives through the `qpak-lib` crate,
which writes each entry to `dest_dir.join(entry_path)` using the path stored in the
archive with no check for `..` components or absolute paths. Running
`qpak unpack <archive>` on an untrusted `PACK` file whose table entry name contains
`../` or an absolute path can cause files to be written outside the chosen output
directory. This is a "zip-slip" / "tar-slip" directory-traversal arbitrary file
write (CWE-22).

### Related

This advisory covers the `qpak` command-line crate. The same flaw in the underlying
library is tracked in the advisory for the `qpak-lib` crate.
