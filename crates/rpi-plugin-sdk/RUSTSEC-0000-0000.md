# `register_entrypoint` was a safe function that dereferenced a raw pointer

From 0.1.4 through 0.1.22, `register_entrypoint` was `pub fn` and took `api: *const PluginApiVt`. After a null check it did `&*api`. A non-null dangling or misaligned pointer is still undefined behavior, and safe Rust can pass one.

The maintainer fixed this in 0.1.23 (commit `cd942b7`, "mark register_entrypoint as unsafe fn"). 0.1.23 and 0.1.24 declare `register_entrypoint` as `pub unsafe fn`.
