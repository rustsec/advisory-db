# Incorrect escaping for `url("")` functions in CSS style attributes

In some cases, quotation marks in CSS url() functions are not escaped. This allows CSS injection. This feature is not enabled by default, so an application is vulnerable if, and only if, the style attribute is allowed and filter_style_properties is used.

As an example, this snippet:

```html
<div style='background:url("cid:\");EVIL_CSS_HERE;background:url(\"cid:")'>
```

Would erroneously "sanitize" to:

```html
<div style='background:url("cid:");EVIL_CSS_HERE;background:url("cid:")'>
```
