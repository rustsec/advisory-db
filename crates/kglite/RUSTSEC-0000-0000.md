# Disk-graph record references can outlive the records they point to

On a disk-mode graph, `GraphRead::node_weight`, `edge_weight`, `edge_weights` and `DirGraph::get_node` returned references into a per-graph arena, with the lifetime of the graph borrow. Safe code could free the arena while such a reference was alive: by dropping a `DiskQueryGuard`, by calling `DirGraph::begin_read_pass` while no guard was held, or by calling `GraphRead::reset_arenas`. Reading through the reference afterwards is a use-after-free.

In-memory and mapped graphs are not affected. The contents of a graph cannot trigger the issue; it depends on the order of calls in the program using the crate.

Fixed in 0.21.8: these reads return a `RecordRef` that owns its copy of the record on disk graphs, and the arena and the APIs that freed it are removed.
