# Degraded secret zeroization capabilities

Versions 0.11.0 and 0.11.1 of vodozemac have degraded secret zeroization
capabilities, due to changes in third-party cryptographic dependencies
(chacha-20poly1305, sha2, hmac), which moved secret zeroization capabilities
behind a feature flag while vodozemac disabled the default feature set.

## Impact

The degraded zeroization capabilities could result in the production of more
memory copies of encryption secrets and secrets could linger in memory longer
than necessary. This marginally increases the risk of sensitive data exposure.
