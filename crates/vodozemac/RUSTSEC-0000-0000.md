# Degraded secret zeroization capabilities

In version 0.11.1 and earlier of vodozemac, the Olm root key ratchet did not
zeroize its HKDF output after use. Each ratchet step left a copy of the new root
key and chain key in freed heap memory.

## Impact

An attacker who can read the process's memory, for example through a separate
memory-disclosure bug, a core dump, or swapped-out pages, may recover root keys
and chain keys from earlier ratchet steps. A leaked chain key allows decrypting
the messages in that chain, weakening Olm's forward secrecy for affected
sessions.
