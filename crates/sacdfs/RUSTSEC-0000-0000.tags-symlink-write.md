# Temporary files in the tags directory written through symlinks

`sacdfs tags` and the MusicBrainz lookup wrote files through a temporary file with a predictable name, opened without `O_EXCL` and following symlinks.
A user who can write the tags directory could plant a symlink there so that sacdfs running as root overwrote the link's target, which can be any file root can write.
The flaw was fixed in 0.6.4, which creates temporary files with `O_EXCL` and `O_NOFOLLOW` under unpredictable names and reads tags files through a single descriptor opened with `O_NOFOLLOW`.
