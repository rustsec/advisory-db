# Deep or cyclic JavaScript values trap the module

### Impact

`stringify` and the other exports that take a JavaScript value converted it with no depth or cycle check. A 2,000-deep or cyclic object trapped with `memory access out of bounds`, and every later call into the same instance trapped too until it was re-created.

### Patches

Fixed in 0.0.55. Values deeper than 128 levels or holding a cycle are refused with an error, and the instance stays usable.

### Workarounds

Bound the depth of objects passed to the module, or re-create the instance after a trap.
