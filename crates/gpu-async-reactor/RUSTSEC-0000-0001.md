# `WordWait` capability can be forged from safe code

In versions before 0.1.1, the fields of `backend::wordwait::WordWait` (feature `wordwait`) were
public. Safe code could therefore construct a value claiming support for `wfet` (aarch64
FEAT_WFxT), `umwait` or `mwaitx` without running the CPU probe. `WordWait::park` then executes an
instruction the CPU may not implement, which is undefined behaviour inside the `asm!` contract
and in practice terminates the process with SIGILL.

From 0.1.1 the fields are private; `WordWait::probe` is the only constructor, and the x86-64
probe checks the highest supported CPUID leaf before reading the feature bits.
