# `wakeup` indexes the event-fd vector with `get_unchecked`

From 0.3.13, `Selector::wakeup(id)` on the epoll, kqueue, and IOCP backends called `self.vec.get_unchecked(id)`. A safe caller can pass an `id` past the vector. The maintainer confirmed the report.

0.3.48, published 2024-12-24, replaced the epoll path with `self.vec[id]`, which panics instead. 0.3.51, the current crates.io release, still uses `get_unchecked` in `kqueue.rs` and `iocp.rs`. There is no release that fixes every backend, so no version is marked patched.
