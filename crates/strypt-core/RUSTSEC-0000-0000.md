# Metadata of JPEG images inside a PDF is not removed

strypt-core is a metadata removal library. Version 0.1.0 did not open the images
inside a PDF: a JPEG placed on a page, or used as a page thumbnail, kept its own
Exif, including GPS position, camera serial number, author and capture time.
Inspection reported nothing, and stripping reported the file clean, so a user
could publish the file believing its metadata removed.

Other formats are not affected.

The flaw was corrected in 0.1.1, which sends every `DCTDecode` stream in a PDF
through the same JPEG handler used for a standalone photo. A PDF cleaned with
0.1.0 can be checked with `exiftool -ee`, which reads the images inside it.
