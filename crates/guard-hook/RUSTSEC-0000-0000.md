# Copyable guard-hook hint allowed shell command injection

Versions 0.2.2 and 0.2.3 of `guard-hook` could place an untrusted Git
remote or branch value into a copyable `agent-guard push` remediation command
without first restricting the value to a shell-safe form.

If an agent supplied a remote or branch containing shell metacharacters and a
human copied the emitted hint into a shell, the appended shell syntax could
execute an additional command with the human's privileges.

Version 0.2.4 validates remote and branch values before constructing a hint.
For an unsafe or ambiguous target, the hook emits an explanation without a
copyable command.
