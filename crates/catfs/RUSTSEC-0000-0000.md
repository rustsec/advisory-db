# `make_self` turns a short-lived reference into `'static`

`make_self` is a safe public function. In 0.8.0 it is:

```rust
pub fn make_self<T>(s: &mut T) -> &'static T {
    unsafe { std::mem::transmute(s) }
}
```

A second copy returns `&'static mut T`. Safe code can call this and keep the reference after `s` is dropped, which is a use-after-free. The report has had no maintainer reply since 2025-11-26, and 0.8.0 is still the latest crates.io release.
