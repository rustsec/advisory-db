# `basek` was removed from crates.io for malicious code

`basek` attempted to install a keylogger on Windows machines.

The malicious crate had 1 version published on 2026-11-18, approximately 6
hours before removal, and had no evidence of actual usage. This crate had no
dependencies on crates.io. (Fortunately, it was also buggy.)

Thanks to the Rust Foundation's crate scanning project for detecting this
campaign.
