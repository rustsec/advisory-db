# `hesk` was removed from crates.io for malicious code

`hesk` attempted to exfiltrate browser state and Exodus wallets.

The malicious crate had 1 version published on 2026-11-18, approximately 6
hours before removal, and had no evidence of actual usage. This crate had two
dependencies on crates.io, both also part of this campaign.

Thanks to the Rust Foundation's crate scanning project for detecting this
campaign.
