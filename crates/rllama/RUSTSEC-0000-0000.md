# `data_u16_to_gpu` builds a slice from a raw pointer

`data_u16_to_gpu` is a safe public method. It takes `data: *const u16` and `nitems`, then calls `slice::from_raw_parts(data, nitems)` and uploads that slice.

Safe Rust can pass a null, dangling, or too-short pointer. `from_raw_parts` then has undefined behavior. 0.3.0, the current crates.io release, still has this signature. The report has had no maintainer reply since 2024-11-30.
