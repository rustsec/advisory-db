# `hugepage_rs::alloc` may cause undefined behavior with zero-sized layouts from safe code

`hugepage_rs::alloc` was a publicly accessible safe function that forwarded a `Layout` to the hugepage allocator's `GlobalAlloc::alloc` implementation without enforcing its safety requirements.
`GlobalAlloc::alloc` requires the layout size to be non-zero. However, the safe wrapper allowed callers to pass a zero-sized `Layout`, violating this precondition without using `unsafe`.
Affected versions therefore exposed an unsafe allocation precondition through safe Rust code, violating Rust's soundness guarantees.

The upstream repository fixed this in version `0.1.2` by marking `alloc` as unsafe and documenting its non-zero-layout requirement.
