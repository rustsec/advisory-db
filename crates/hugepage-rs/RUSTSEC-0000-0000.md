# `hugepage_rs::Box::new` may cause undefined behavior when initializing memory

`hugepage_rs::Box::new` incorrectly initialized freshly allocated memory. Earlier implementations could either drop an uninitialized `T` or create a mutable reference before the memory contained a valid `T`, causing undefined behavior even when called from safe Rust code.

The issue was fixed in version `0.1.2` by using `ptr::write(nn.as_ptr(), data)` to initialize memory directly through a raw pointer.
