# `ds18b20` appears to be unmaintained

`ds18b20` is an embedded Rust driver for the DS18B20 temperature sensor.
The latest release, `0.1.1`, was published on August 19, 2020.
The upstream default branch's latest commit is from the same date.
[Release history](https://docs.rs/crate/ds18b20/0.1.1) ·
[Latest upstream commit](https://github.com/fuchsnj/ds18b20/commit/8442e5edd77d530b2e29c3cd558616ee15101738)

example (March 2020), reporting a temperature conversion problem (January
2023), or discussing the `embedded-hal` 1.0 migration (December 2023).
