# Access-control bypasses expose server-managed state and private keys in solid-pod-rs-server

`solid-pod-rs-server` versions from `0.4.0-alpha.2` up to and including
`0.5.0-alpha.12` contain several authorisation flaws:

- **COPY** did not require read access on its `Source`, and copied the source's
  `.acl` sidecar without a Control check. Any principal with Write on any
  container could copy a private resource, or an ACL, into a location they can
  read.
- **Glob GET** checked read access on the container only. Children with a
  stricter ACL, `.acl` files and `.prov.ttl` provenance files were returned.
- **Server-managed state was reachable as ordinary pod content.**
  `/.well-known/token/`, `/.well-known/gitmark/` and `/.well-known/prov/` hold
  anchor signing keys (plain JSON) and anchoring state; `/.well-known/webledgers/`
  holds every principal's balance. Under a public-read pod root these were
  readable by anonymous callers, and through COPY by any Writer. A Writer could
  overwrite the web ledger and forge a balance.
- **MCP** (`--mcp`) did not canonicalise paths before its permission check, so
  spellings such as `//.well-known/token/x.json` reached guarded files, and it
  skipped the dotfile allowlist, allowing a Writer to create `.git/config` and
  `*.meta.json` files.
- **Container `index.html` negotiation** served `index.html` after checking
  read access on the container only.
- **Payment ledger updates for anchoring** were not serialised, allowing lost
  updates on concurrent charges.

Impact: disclosure of private keys that control anchoring funds, forgery of
payment balances, and disclosure of resources protected by narrower ACLs.

## Patches

Fixed in `0.5.0-alpha.13`. All affected versions are yanked.

## Workarounds

None complete. Do not grant public Read on the pod root, and do not enable
`--mcp`, until upgraded.

## Required operator action

Operators who ran an affected version with a public-read pod root, or with
`--mcp` enabled, should treat trail signing keys under `/.well-known/token/` and
`/.well-known/gitmark/` as disclosed: rotate them, and audit balances under
`/.well-known/webledgers/`.
