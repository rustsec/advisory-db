# In-place writes expose the file mode and follow planted symlinks

### Impact

`noyafmt --write` wrote the new contents to a temp file with a predictable name, opened without `O_EXCL` and with default permissions, and copied the original mode only after writing. While it ran, the full contents of a 0600 file sat in a 0644 file, and someone able to create files in the directory could plant a symlink at the temp name to redirect the write.

### Patches

Fixed in 0.0.55. The temp file is created exclusively, with a random name and the target's mode, before anything is written.

### Workarounds

Do not run `--write` in directories other users can write to.
