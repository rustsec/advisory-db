# UB can be reached from safe code

The variance of `RefSwap` and `OptionRefSwap` were incorrect, possibly allowing use-after-free.

`OptionRefSwap::into_inner` did not check for null.

The fix is to make `RefSwap` and `OptionRefSwap` invariant, and to change `OptionRefSwap::into_inner` to return an option.
It is available in version 0.1.3.
If your project still compiles with 0.1.3 then it is not affected by the unsoundness on version 0.1.2
