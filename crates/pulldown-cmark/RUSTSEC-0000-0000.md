# Quadratic-time footnote parsing can cause denial of service

When the `ENABLE_FOOTNOTES` option is enabled, `pulldown-cmark` versions
0.10.0 through 0.13.4 can exhibit quadratic-time behavior when parsing
specially crafted Markdown containing repeated lines starting with `[^`.

The paragraph-interruption check repeatedly performs UTF-8 validation on
`bytes[2..]`, which can extend over the remaining input rather than being
restricted to the current line. Repeating this check across many lines can
cause excessive CPU consumption. Applications that parse attacker-controlled
Markdown with footnotes enabled may consequently be susceptible to denial of
service.

The vulnerable check was introduced in commit [`3d184fb`](https://github.com/pulldown-cmark/pulldown-cmark/commit/3d184fb),
which first appeared in the 0.10.0 release. Regression testing of the crafted
input exhibited quadratic-time scaling in 0.10.0; the same behavior was not
observed in 0.9.6. The issue was originally reported by Côme Bruneteau in
[issue #1076](https://github.com/pulldown-cmark/pulldown-cmark/issues/1076)
following security-oriented fuzz testing.

The issue was addressed upstream in
[pull request #1136](https://github.com/pulldown-cmark/pulldown-cmark/pull/1136)
and the fix was backported for the
[0.13.5 release](https://github.com/pulldown-cmark/pulldown-cmark/pull/1181).
Users should upgrade to `pulldown-cmark` 0.13.5 or later.

If upgrading is not immediately possible, disabling `ENABLE_FOOTNOTES`
when processing untrusted Markdown avoids this particular trigger.
