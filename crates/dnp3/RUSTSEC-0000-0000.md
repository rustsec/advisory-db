# Remotely reachable panic in the outstation

A specially crafted request makes the outstation's task panic. The outstation
stops running until the application recreates it. The request needs no
authentication on a plain TCP, UDP or serial link; with TLS it has to come from
a peer whose certificate the outstation trusts.

1.8.0 rejects the request. There is no workaround.
