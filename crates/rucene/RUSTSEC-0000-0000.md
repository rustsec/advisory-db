# `BytesRefHash::byte_pool` dereferences a raw pool pointer

`BytesRefHash` stores `pool: *mut ByteBlockPool`. `byte_pool` is safe and returns `&*self.pool`. Nothing in that function checks that `pool` is non-null and aligned.

Safe code that can build a `BytesRefHash` with a null or dangling pool gets undefined behavior on the dereference. 0.1.1 still has `byte_pool`. The report has had no maintainer reply since 2024-12-09.
