# Double free / use-after-free in `VecDeque::clear` when an element's `Drop` panics

`VecDeque::clear` drops the elements before resetting `end`, `start` and
`is_full`. If an element's `Drop` panics during the drop loop, the metadata is
left stale, so the queue still treats those slots as holding live elements.
Since `Drop for VecDeque` calls `clear()` again, dropping the queue during
unwinding revisits the already-dropped slots — a double free (CWE-415) /
use-after-free (CWE-416) reachable from safe Rust.

## Mitigation

Update to 0.5.2.
