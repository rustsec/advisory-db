# `Value::clone` can wrap the native reference count and release a live value

`Clone` for `Value` calls `ray_retain` on the native object, and `Drop` calls `ray_release`. For values outside an arena, `ray_retain` increments the 32-bit count without checking for overflow. `std::mem::forget` is safe, so safe code can clone a `Value` until the count wraps, and a later release can free the native object while another safe handle is still live.

In our full-width run, a driver with no `unsafe` code reaches this release with rayforce 1.2.0 and its vendored core 2.11.0.

We separately checked the source of rayforce 1.5.0 (rayforce-sys 1.5.0) and found the increment unchanged; we did not run that version. No fixed version is available.
