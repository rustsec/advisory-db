# URL scheme check bypass allows `javascript:` URLs in attributes

URLs built from more than one value, or preceded by whitespace in the
template, skipped the scheme check, allowing `javascript:` URLs in
attributes.

Upgrade to 0.9.3 or later. The affected versions have been yanked.
